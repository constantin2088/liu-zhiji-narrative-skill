# 可填写工作表

## 第1步
界定要审的叙事、版本、受众与作者所在组织，注明谁委托、谁能删改、谁受益。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
把事件事实、动机推断、价值评价和修辞分列，引用与转述分别定位。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
核查哪些人被写入、哪些事件被省略，比较成功与失败受到的取材标准，不能只查已写的句子。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
检查叙事是否因委托或利益改变词语、因果、时序及功劳归属；提出可复核差异，不猜测作者内心。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
给出最小诚实改写，保留不知道、相反材料与未有发言机会的一方；隐私可匿名，不能靠人身曝光证明真实。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
保存原版、修订理由与异议，选择适当安全范围提交复核；直书取向不等于拒绝所有保密和风险控制。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

按原文位置安全应用经作者确认的修改，检测重叠、越界与旧文不一致；不评价修改思想。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_revisions.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
